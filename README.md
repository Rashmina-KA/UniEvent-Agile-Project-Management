# UniEvent – Agile Project Management

A simulated Agile project demonstrating practical project management, Scrum delivery, project tracking, documentation, and reporting practices for a university event management system.

## 📌 Project Overview

**UniEvent** is a simulated web-based University Event Management System designed to simplify event discovery and registration for students while helping event organizers manage events and participant registrations.

This project focuses on the **project management and Agile delivery side** of software development rather than building the complete application.

The project demonstrates how an Agile project can be planned, tracked, documented, and monitored using industry-relevant tools and practices.

---

## 🎯 Project Objective

The main objective is to plan and manage the development of a university event management platform that enables:

- Students to discover available university events
- Students to register for events
- Students to receive registration confirmations
- Organizers to create and manage events
- Organizers to monitor event registrations

---
